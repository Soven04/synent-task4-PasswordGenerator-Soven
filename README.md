# Password Generator

A simple command-line password generator built using Python.

The program generates a random password based on the length specified by the user. Each password contains uppercase letters, lowercase letters, numbers, and special characters.

## Features

- Generates random passwords
- Uses Python's `random` module
- Includes uppercase letters
- Includes lowercase letters
- Includes numbers
- Includes special characters
- Allows the user to choose the password length
- Ensures at least one character from each required category
- Handles invalid input

## Requirements

- Python 3.x

No external libraries are required.
